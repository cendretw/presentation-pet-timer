# Privacy Policy for 簡報小助手 - 寵物計時提醒

**Last Updated:** November 2026

## 1. Data Collection and Usage
**簡報小助手 - 寵物計時提醒** ("the Extension") respects your privacy. We do **not** collect, store, transmit, or sell any personally identifiable information (PII), browsing history, website content, or user activity data to any external servers or third parties.

## 2. Local Storage
The Extension uses Chrome's `storage` API solely to save your local preferences (such as custom timer intervals, reminder messages, and selected virtual pet characters) directly on your own device so your settings persist between browser sessions.

## 3. Host Permissions
Host permissions are strictly used to render the visual floating timer overlay on top of your active presentation tab. The Extension does not read, modify, or extract any data from the web pages you visit.

## 4. Contact
If you have any questions regarding this Privacy Policy, please contact the developer via the Chrome Web Store support page.
